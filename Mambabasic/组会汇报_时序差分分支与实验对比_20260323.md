# 流化床视频分类阶段性汇报

## 1. 当前结论

当前最优实验为：

- `Mambabasic/run_combo_20260316_131051_f16_bs8x1_cls38_hlr1e-03`
- 最优验证准确率：`87.41%`
- 最优 epoch：`36`
- 总训练时间：`12.76 h`

现阶段可以得到两个较可靠的判断：

1. 对当前流化床图像任务，强图像增强大概率不利于性能。
2. 强图像增强会显著增加训练耗时。

但还不能严格下结论说“流化床图像天然最适合完全不做预处理”，因为三次实验不只是增强策略不同，模型目录、学习率、正则化、辅助损失权重、训练轮数也同时变化了。

### 2.2 增强策略对比

`Mambabasic` 的 `dataset_combo.py` 不是完全无增强，而是弱增强：

- resize 到 `224x224`
- 随机水平翻转
- 轻微亮度扰动

`MambaSformer2` 的 `dataset_combo.py` 是更强增强：

- `RandomResizedCrop`
- `HorizontalFlip`
- `Affine`
- brightness / contrast
- Gaussian blur
- noise

因此，更准确的说法应是：

- 当前最优结果来自“弱增强方案”，不是“零预处理方案”。

### 2.3 时间开销对比

按 summary 和 log 估算：

- `Mambabasic`：约 `19.1 min/epoch`
- `MambaSformer2(run_20260319)`：约 `42.5 min/epoch`

从训练日志看，batch 时间大致为：

- `Mambabasic`：约 `1.2 s/batch`
- `MambaSformer2(run_20260319)`：约 `2.6 s/batch`

说明更重的数据增强明显拉长了训练时间。原因主要有两点：

1. 每个 batch 需要执行更多 CPU / GPU 预处理操作。
2. 训练轮数也更多，导致总耗时进一步放大。

## 3. 为什么强增强可能不适合流化床图像

流化床图像和自然图像分类不同。自然图像里，目标物体位置变化、轻微裁剪、平移、模糊通常不改变类别；但流化床视频的类别判别往往和空间结构强相关：

- 床层高度
- 气泡区域位置
- 边界形态
- 颗粒分布纹理
- 某些关键区域的亮暗和扰动模式

如果对这类图像执行随机裁剪、平移、仿射、模糊、加噪声，模型看到的就不再是原始工艺结构，而是被扰动后的结构。这样虽然在自然图像里可能提高泛化，但在工业过程图像里反而可能破坏真正有判别价值的信息。

因此，当前结果更支持下面这个判断：

- 该任务更适合保留原始空间结构的弱增强，而不是强扰动增强。

## 4. 你现在的模型已经做时序建模了吗

答案是：`做了`，而且是明确做了时序建模。

当前主干可以概括为：

- 输入一个样本：`16` 张连续帧
- 每帧切成 patch token
- 在时序方向使用 `Temporal Mamba`
- 在空间方向使用 `Spatial Attention`
- 再经过 MLP 和分类头输出结果

从代码实现看，时序模块会把同一空间位置在 `T=16` 帧上的 token 取出来，沿时间维做 Mamba 扫描。这说明它不是把 16 张图当成无顺序图片堆起来，而是在学习帧间依赖关系。

所以，当前模型已经是“时序模型”，这一点没有问题。

## 5. 那为什么还要做 B：时序差分分支

### 5.1 核心区别

当前模型的时序建模方式是：

- 输入：原始帧序列 `frame_1, frame_2, ..., frame_16`
- 目标：让模型自己从原始像素中学出哪些变化有用

差分分支的方式是：

- 输入：`diff_t = frame_t - frame_(t-1)`
- 第一帧用 0 补齐
- 目标：把“运动变化信息”显式提供给模型

两者的区别可以概括为：

- 当前主干：`隐式建模时序`
- 差分分支：`显式建模运动`

这两种信息不是重复关系，而是互补关系。

### 5.2 作用是不是针对一个样本的 16 张图

是的。

你当前一个样本就是 `16` 张连续帧，那么差分分支也是作用在这 `16` 张图上。

具体做法：

- 原始外观分支输入：`[frame_1, frame_2, ..., frame_16]`
- 差分运动分支输入：`[0, frame_2-frame_1, frame_3-frame_2, ..., frame_16-frame_15]`

因此差分分支不是额外引入新的样本定义，而是在同一个样本内部，对 16 帧再构造一组运动表征。

### 5.3 原理

原始帧主要包含：

- 外观
- 背景
- 纹理
- 结构

差分帧主要突出：

- 哪些区域发生了变化
- 变化幅度有多大
- 变化分布在哪些位置

这样做的效果是：

- 静止背景会被弱化
- 动态区域会被强化
- 运动模式被更直接地暴露给模型

对于流化床任务，这类显式运动信息往往对应：

- 气泡生成与上升
- 团聚与破碎
- 局部波动强度
- 边界抖动
- 不同工况下的扰动节律

### 5.4 与当前 TimeSformer + Mamba 的关系

当前 TimeSformer + Mamba 已经能学时序，但它学的是：

- “原始视频里什么变化值得关注”

差分分支做的是：

- “先把变化本身提取出来，再让模型去判断这些变化属于哪一类”

可以理解为：

- 主干分支更擅长 `appearance + implicit temporal relation`
- 差分分支更擅长 `explicit motion cue`

所以差分分支不是否定现有时序建模，而是在现有时序建模之上增加一个更容易学到动态模式的辅助输入通道。

## 6. 未来优先做的两件事

建议优先级：

1. `B 时序差分分支`
2. `A 多尺度输入分支`

原因是 B 为模型引入了新的信息类型，创新性和收益预期都更直接；A 更像是改进输入组织方式，也很合理，但优先级略低于 B。

## 7. 方案 B：时序差分分支

### 7.1 方案定义

在 dataset 中，除原始 `frames` 外，再生成一份 `diff_frames`：

- `diff_1 = 0`
- `diff_t = frame_t - frame_(t-1)`，`t=2...16`

模型中建立两路：

- appearance branch：处理原始帧
- motion branch：处理差分帧

最后做融合：

- `concat`
- 或 `gated fusion`

### 7.2 具体执行步骤

#### 第一步：修改 dataset

当前 `__getitem__` 返回：

- `frames`
- `labels`

修改后返回：

- `frames`
- `diff_frames`
- `labels`

差分生成方式：

1. 先读取并归一化 `frames`
2. 构造同 shape 的 `diff_frames`
3. 第一帧全 0
4. 其余帧为相邻帧差分

注意事项：

- 差分最好在归一化前还是后计算，需要做一次对比实验。
- 初始建议：在 `[0,1]` 浮点张量上先做差分，再根据需要做标准化。

#### 第二步：修改模型

新增双分支结构：

- `appearance_encoder(frames)`
- `motion_encoder(diff_frames)`

起步方案建议：

- 两个分支结构相同
- 先不共享参数
- 最后取两个 CLS token 或 pooled feature，直接 `concat`
- 接一个线性层分类

更进一步可做：

- 加一个门控模块，自动决定当前样本更依赖 appearance 还是 motion

#### 第三步：修改训练

`forward` 改为：

- 输入 `frames, diff_frames`
- 输出 `combo_logits, gas_logits`

loss 先保持和当前一致：

- 主分类 loss
- gas 辅助 loss

先不要一次引入太多变化，保证能清楚判断差分分支本身的收益。

### 7.3 预期好处

1. 显式强化动态信息，提升易混类别区分能力。
2. 弥补纯 appearance 建模对“变化过程”不敏感的问题。
3. 论文动机更充分：工业流态不仅由静态形态决定，也由动态演化模式决定。
4. 相比直接加大分辨率，差分分支增加的是“新信息类型”，不是单纯增加算力消耗。

### 7.4 风险与注意点

1. 差分容易引入噪声，对光照抖动也敏感。
2. 若采样帧间隔过小，差分可能过弱。
3. 若双分支都完整复制，训练成本会上升。

对应对策：

- 先做最小版验证收益
- 必要时对差分做轻量平滑或截断
- 如果显存吃紧，再考虑共享前层

## 8. 方案 A：多尺度输入分支

### 8.1 方案定义

对同一个视频样本，同时构造两路输入：

- 全局分支：整图 resize 到 `224`
- 局部分支：对关键区域 crop 后 resize 到 `224`

最终将全局和局部特征融合。

### 8.2 原理

全局分支擅长捕获：

- 整体流型
- 大尺度结构
- 床层整体形态

局部分支擅长捕获：

- 细粒度纹理
- 小气泡边界
- 局部团聚/扰动
- 工艺关键区域细节

多尺度本质上是在同时建模：

- 宏观形态
- 微观细节

### 8.3 具体执行步骤

#### 第一步：定义局部区域

局部分支有几种实现方式：

1. 中心带 crop
2. 人工指定工艺关键区域
3. 按固定比例裁出床层主区域

建议先用最稳定、最容易复现的固定 crop，不要一开始就做复杂检测。

#### 第二步：修改 dataset

返回：

- `global_frames`
- `local_frames`
- `labels`

其中：

- `global_frames` 维持当前流程
- `local_frames` 对每帧做相同位置 crop，再 resize

#### 第三步：修改模型

建立两路编码器：

- global encoder
- local encoder

融合方式建议从简：

- 两路特征 `concat`
- 再接分类头

### 8.4 预期好处

1. 弥补整图缩放导致的局部细节损失。
2. 更聚焦真正有工艺意义的关键区域。
3. 比整图直接升到 `384` 更高效，因为不是把所有区域都变贵，而是把算力分配给更有信息的区域。
4. 论文叙事更自然：流化床工况识别同时依赖整体流态和局部结构。

### 8.5 风险与注意点

1. 若局部 crop 位置选错，可能截掉有效信息。
2. 双分支会带来额外算力开销。
3. 若全局和局部信息高度重复，收益可能有限。

## 9. 推荐实验路线

### 9.1 先做严格对照

先补一个严格 ablation：

- 同一个代码库
- 同一个模型
- 同一组学习率
- 只切换 `augment on/off`

目的：

- 证明“强增强不适合当前任务”这一点是可靠的，不是被其他超参混淆出来的结果。

### 9.2 然后优先做 B

建议顺序：

1. 保留当前最优弱增强设置
2. 在此基础上加差分分支
3. 与当前最优单分支模型对比
4. 若有效，再尝试门控融合

### 9.3 再做 A

建议先做最简单固定 crop 版本：

- 全局 224
- 局部固定区域 224
- 双分支 concat

先验证是否有稳定增益，再决定是否做更复杂的局部区域选择。

## 10. 组会可直接汇报的结论版

### 10.1 当前结果结论

当前 38 类组合分类任务中，最优实验为 `Mambabasic/run_combo_20260316_131051_f16_bs8x1_cls38_hlr1e-03`，验证准确率达到 `87.41%`。相比两组带更强数据增强的实验，当前弱增强方案在准确率和训练效率上都更优，说明对流化床图像这类固定视角、空间结构强相关的工业过程数据，过强的随机裁剪、平移、模糊和噪声扰动可能破坏真实判别信息。

### 10.2 为什么还要做时序差分分支

虽然当前主干已经是 TimeSformer + Mamba 的时序模型，能够对 16 帧序列进行时序建模，但它处理的是原始帧序列，主要学习的是隐式时序关系。时序差分分支进一步显式构造相邻帧差值，把运动变化区域直接突出出来，从而将“动态流态变化”作为额外判别信息输入模型。两者不是替代关系，而是互补关系。

### 10.3 后续工作重点

后续准备优先做两项工作：

1. 时序差分分支。对每个 16 帧样本额外构造差分序列，建立 appearance branch + motion branch，通过融合提升对动态流态类别的识别能力。
2. 多尺度输入分支。构造全局视图和局部关键区域视图，联合建模宏观流型与局部细节，提升细粒度分类能力。

### 10.4 预期贡献

这两项工作分别对应两类信息增强：

- 时序差分分支增强动态信息表达
- 多尺度分支增强空间多粒度信息表达

若实验有效，可以形成较清晰的论文主线：在流化床工业视频识别中，同时引入显式运动建模和多尺度结构建模，以提升复杂工况分类性能。

## 11. 一句话版答辩口径

当前模型已经具备时序建模能力，但主要是从原始帧里隐式学习时间关系；时序差分分支的意义在于把相邻帧变化显式提出来，让模型更直接感知流态动态演化。结合现有结果，我们下一步优先做显式运动分支，再做全局-局部多尺度分支，用来提升流化床视频分类的动态判别能力和细粒度识别能力。
